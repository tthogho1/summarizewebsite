# SummarizeWiki

A Go project for summarizing Wikipedia articles.

## Project Structure

- `main.go`: Entry point for the application.
- `go.mod`: Go module definition.
- `cmd/`: For main application commands (future expansion).
- `pkg/`: For reusable packages (future expansion).
- `internal/`: For internal packages (future expansion).

## Getting Started

1. Ensure you have Go installed (https://golang.org/doc/install).
2. Build and run:
   ```sh
   go run main.go
   ```
